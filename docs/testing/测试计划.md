# 自动摘要生成系统测试计划

## 1. 简介

### 1.1 目的
本文档旨在概述“计算机科学领域英文技术文档自动摘要生成系统”的测试策略、范围和方法。该计划确保系统满足高质量 NLP 应用预期的功能需求和性能标准。

### 1.2 范围
本测试计划涵盖系统的以下组件：
- **数据预处理与加载**：验证数据摄入、清洗和分词。
- **模型训练**：验证训练循环、损失计算和检查点保存。
- **推理引擎**：使用 T5 模型测试摘要生成能力。
- **评估指标**：确保准确计算 ROUGE 和 BLEU 分数。
- **用户界面**：Web UI (Streamlit) 和 GUI 的功能测试。
- **对比模块**：验证不同模型之间的对比逻辑。

范围外：
- 极高负载下的压力测试（超过 100 个并发用户）。
- 安全渗透测试（重点关注功能和模型性能）。

## 2. 测试策略

### 2.1 单元测试
- **目标**：验证单个函数和类的正确性。
- **工具**：`unittest`, `pytest`。
- **关键模块**：`utils.data_loader`, `utils.metrics`, `models.t5_model`。

### 2.2 集成测试
- **目标**：验证不同模块能否正确协同工作。
- **场景**：
    - 数据加载器 -> 分词器 -> 模型输入
    - 模型输出 -> 解码器 -> 指标计算
    - Web UI -> 推理引擎 -> 显示

### 2.3 系统测试
- **目标**：验证应用程序的端到端流程。
- **场景**：上传文档、生成摘要并查看结果。

### 2.4 性能测试
- **目标**：测量推理时间和资源使用情况。
- **指标**：每次请求的延迟、GPU 显存消耗。

## 3. 测试环境

### 3.1 硬件
- **CPU**：Intel Core i7 或同等处理器
- **内存**：16GB+
- **GPU**：NVIDIA GeForce RTX 3060 或更高（启用 CUDA）

### 3.2 软件
- **操作系统**：Windows 10/11 或 Linux (Ubuntu 20.04+)
- **Python**：3.8+
- **库**：PyTorch, Transformers, Streamlit, ROUGE-Score, SacreBLEU
