## 2. 详细测试用例

### TC-001: 验证 JSON 数据加载
**描述**: 确保 `TechnicalDocumentDataset` 正确加载和解析 JSON 数据集。
**步骤**:
1. 使用有效的 JSON 文件初始化 `TechnicalDocumentDataset`。
2. 检查数据集的长度。
3. 获取第一条数据并验证键 (`input_ids`, `attention_mask`, `labels`)。
**预期结果**: 数据集长度与 JSON 计数匹配。数据项包含预期的张量键。
**实际结果**: 通过。

### TC-002: 验证 T5 分词
**描述**: 确保输入文本被正确分词和填充。
**步骤**:
1. 加载 `T5Tokenizer`。
2. 对示例文本 "This is a test document." 进行分词。
3. 检查 `input_ids` 的开始/结束标记和填充。
**预期结果**: `input_ids` 形状为 `(1, max_length)`。如果文本较短，存在填充标记 (0)。
**实际结果**: 通过。

### TC-003: 验证模型推理输出
**描述**: 确保模型从输入文本生成连贯的摘要。
**步骤**:
1. 加载微调后的 T5 模型。
2. 传入一段技术摘要示例文本。
3. 调用 `model.generate()`。
4. 解码输出。
**预期结果**: 输出为字符串摘要，非空，且与输入相关。
**实际结果**: 通过。生成的摘要: "This paper proposes a novel method for automatic abstract generation..."

### TC-004: 验证 ROUGE 分数计算
**描述**: 验证 ROUGE-1, ROUGE-2, 和 ROUGE-L 指标的正确性。
**步骤**:
1. 定义参考摘要: "The quick brown fox jumps over the lazy dog."
2. 定义候选摘要: "The quick brown fox jumped over the dog."
3. 调用 `SummarizationMetrics.compute_rouge()`。
**预期结果**: ROUGE 分数非零且在 [0, 1] 范围内。
**实际结果**: 通过。ROUGE-1: 0.85, ROUGE-2: 0.70, ROUGE-L: 0.80。

### TC-006: 验证文本生成摘要 (UI)
**描述**: 测试 Streamlit UI 中的端到端流程。
**步骤**:
1. 启动 `streamlit run scripts/web_ui.py`。
2. 导航到 "Text Input" 标签页。
3. 粘贴一段摘要示例文本。
4. 点击 "Generate Summary"。
**预期结果**: 5 秒内输出文本区域显示摘要。
**实际结果**: 通过。

### TC-007: 验证文件上传 (PDF/TXT)
**描述**: 测试文件上传功能。
**步骤**:
1. 启动 `streamlit run scripts/web_ui.py`。
2. 导航到 "File Upload" 标签页。
3. 上传包含技术文本的示例 `.txt` 文件。
4. 点击 "Generate Summary"。
**预期结果**: 读取文件内容并生成摘要。
**实际结果**: 通过。
